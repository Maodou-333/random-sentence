# 随机造句

一个使用原生 HTML、CSS 和 JavaScript 制作的随机句子生成网站，可以直接部署到 GitHub Pages。

## 本地打开

直接双击 `index.html` 即可运行，无需安装任何软件或依赖。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库。
2. 将 ZIP 解压后的所有文件上传到仓库根目录。
3. 打开仓库的 `Settings` → `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/ (root)`，然后点击 `Save`。
6. 等待约 1—3 分钟，GitHub 会显示网站地址。

## 文件说明

- `index.html`：网页结构
- `style.css`：页面样式
- `script.js`：随机生成、锁定与复制功能
